# 无线电入群测试

> 让新人群员答一套随机题：每题给一个真实案例，判断它属于
> **无违规 / 轻微违规 / 严重违规** 哪一档。
> 答对 6 题即通过，生成一张带凭证码的成绩单 —— 截图发群里，管理员一眼就能核对。

**依据**：《半间猫窝（Cat Ham、小猫Ham）群规》修订 3（2026-08-16）

## ⚡ 玩法：三十秒看懂

1. 群员打开链接，填自己的群昵称
2. 从 **40 道题**里**随机抽 10 题**，每题一个真实案例
3. 三选一：无违规 / 轻微违规 / 严重违规
4. 答对 6 题就过，生成一张**带凭证码的成绩单**
5. 截图发群里，管理员核对凭证码放人

| 项目 | 设置 |
|---|---|
| 题库量 | **40 道**（无违规 10 / 轻微违规 20 / 严重违规 10） |
| 每次抽题 | **10 道**，题目与选项都会打乱 |
| 及格线 | **60 分**（答对 6 题） |
| 其他门槛 | **无** —— 只看总分，没有必答区、没有限时 |
| 重考 | 不限次数 |

### 手感上做了这些

- **3D 立体选项**，按下去会真的下沉
- 答对：粒子爆炸（**篮球 + 星星**）+「叮咚」音效 + 进度条扫光 + 手机震动
- 答错：选项红框抖动 + **整页屏幕震动**
- **连击 COMBO**：连对 2 次开始弹提示，连对 5 次触发全屏彩虹描边
- 结果页：分数从 0 滚上去 + 通过时**彩带雨**
- 进度条上跑着**蔡徐坤挡板小人**，失败界面是**科比 24 号**
- 文案是冷幽默风，答完按分数给不同评语（满分 / 稳 / 压线 / 差一点 都有话说）

## 🖥 想跑后端（可选）

```bash
cd group-rules-quiz\服务端
node server.js
```

- **零依赖**，不用 `npm install`，Node 18+ 就能跑
- 起来后访问 `http://127.0.0.1:8788/quiz`
- 能接 QQ 机器人（NapCat / Lagrange / go-cqhttp）：群里发「**答题**」自动发链接，交卷后**成绩自动回群**
- 详细步骤见 `说明-接QQbot.md`

> 只想发给群员做单机版？**直接发 `半间猫窝群规测验.html` 就行**，不用后端。

## 🔧 常用操作

**改题目**
```
1. 编辑 group-rules-quiz\群规问卷.html，搜「② 题库区」
2. node 导出题库.js        （同步给服务端）
3. node 校验题库.js        （体检，可选）
4. 重启服务
```

**看谁没通过**
```bash
curl "http://127.0.0.1:8788/api/list?token=你的adminToken&fail=1"
```

**成绩记录**：`group-rules-quiz\服务端\results.jsonl`，一行一条，可直接丢进 Excel。

## ⚠️ 两条重要事实

1. **单文件版 vs 开发版**
   `半间猫窝群规测验.html` 是**图片内嵌版**，发群里用这个；
   项目里的 `群规问卷.html` 是开发版（85 KB，引用 `素材\` 目录），改东西用那个。

2. **服务端模式看不到答案**
   为了防作弊，取题接口不下发正确答案，所以服务端模式**无法在答题时即时判分**，
   答完统一在结果页给完整反馈。单文件本地模式则可以即时判分。
